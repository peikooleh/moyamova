# MOYAMOVA 1.12.13

**MOYAMOVA** — офлайн-тренажёр для изучения иностранных языков на карточках.  
Работает прямо в браузере, без регистрации и без обязательного бэкенда.

- 📱 Оптимизировано под мобильные устройства (портретный режим)
- 📴 Работает офлайн через PWA + Service Worker
- 🧠 Движок тренировки: звёзды + сеты + режимы (Auto / Reverse / Focus)
- 📊 Статистика прогресса и активности (тепловая карта)
- 💾 Резервные копии: экспорт / импорт прогресса одним файлом
- 🤖 Поддержка Android TWA (assetlinks)

---

## 🧭 Быстрый старт

1. Открой раздел **«Словари»**.
2. Выбери деку и начни тренировку.
3. Отвечай на карточки — звёзды растут при правильных ответах.
4. Ошибки автоматически попадают в **«Мои ошибки»**.
5. В burger-меню можно включить Auto / Reverse / Focus / TTS.
6. Для стабильной работы рекомендуется установить приложение как **PWA**.

## 🚀 Что умеет приложение

### 🎴 Словари и деки

- Готовые словари по языкам:
  - **DE** (немецкий) — базовые деки + отдельные тренеры
  - **EN** (английский)
  - **Lernpunkt** — отдельная учебная ветка/деки (может быть скрыта через visibility-gate)
- Раздел **«Словари»**:
  - список доступных дек;
  - прогресс по каждой деке (сколько выучено);
  - переключение между языками через флаги;
  - запуск тренировки по выбранной деке.

Встроенные словари хранятся как JSON (`dicts/data/...`) и регистрируются через `DeckLoader`. В ветке 1.5.x загрузчик предварительно поднимает все встроенные деки при старте для полной совместимости с существующим синхронным UI; API `DeckLoader.load(key)` уже подготовлен для последующего перехода на загрузку по требованию.

Каждое слово можно:
- выучить через тренажёр;
- добавить в избранное;
- при ошибке оно автоматически попадает в «Мои ошибки».

---

### ⭐ Тренажёр и прогресс

- Алгоритм на основе **звёздочек**:
  - у каждого слова есть уровень освоения от `0` до `starsMax`;
  - тренажёр повышает или понижает уровень в зависимости от ответа;
  - слово считается *выученным*, когда достигает максимального уровня.
- Сеты:
  - тренировка идёт сетами;
  - есть круговое продвижение по сетам;
  - (опционально) автопереход по сетам.
- Доп. логика:
  - «cooldown» — защита от фарма звёзд при сериях ошибок;
  - отдельная работа с сериями ошибок по слову.

---

## ⏱️ Что такое сет

Тренировка разбита на сеты — небольшие порции слов/упражнений.  
Один сет обычно занимает несколько минут (зависит от режима и сложности).  
Есть круговое продвижение по сетам и возможность ручного или автоматического перехода.

---

### 🔁 Режимы тренировки (burger → настройки)

- **Авто (Auto step)** — автопереход по сетам (можно отключить → ручной режим).
- **Обратный перевод (Reverse)** — тренировка в обратном направлении (симметрично для режимов и виртуальных дек).
- **Концентрация (Focus)**:
  - Сеты / Контекст — можно скрывать/показывать части UI для фокуса.
- **Озвучка (TTS)**:
  - отдельные режимы для слов и примеров;
  - примеры озвучиваются после правильного ответа;
  - язык/голос выбирается по активной деке.

---

### 🧩 Фильтры (темы/ограничения)

- Шторка фильтров работает по сценарию **draft → Apply**.
- Нет live-apply и rollback — изменения вступают в силу только после подтверждения.
- Есть защита от «усыхания» набора: тренер гарантирует достаточное число вариантов.
- Для виртуальных дек `favorites:*` / `mistakes:*` фильтры **не применяются**.

---

### 📚 Избранное и Мои ошибки

- **Избранное**:
  - отдельный экран со словами, отмеченными вручную;
  - можно запускать как отдельную тренировку.
- **Мои ошибки**:
  - виртуальная дека, собирающая слова с неправильными ответами;
  - помогает целенаправленно прорабатывать слабые места.

---

### 📚 Дополнительные тренеры

#### 🧾 Тренер артиклей (DE)
Отдельная подсистема:
- собственный прогресс и статистика;
- избранное и ошибки артиклей;
- автопереход по сетам работает симметрично word-trainer;
- в режиме ошибок добавление в избранное блокируется.

#### 🔤 Тренер предлогов (EN/DE)
- отдельный датасет паттернов;
- запускается только из строки предлогов;
- использует собственный ключ тренера (`*_prepositions_trainer`);
- интегрирован в общую навигацию и режимы.

---

### 📊 Статистика изучения

Экран **«Статистика»** показывает:

- количество слов и прогресс по декам;
- сколько дек начато и завершено;
- распределение по частям речи (кольцевые диаграммы);
- активность по дням (тепловая карта).

Активность:
- 4 уровня интенсивности;
- максимум достигается при **3+ завершённых сетах за день**.

---

### 📱 Web vs PWA

Приложение можно использовать прямо в браузере.  
Однако часть расширенных настроек и более стабильная работа доступны в установленной версии (PWA / TWA).

Рекомендуемый режим — установка как PWA.

## 🧩 Архитектура проекта

Проект построен на чистом JavaScript без фреймворков.

Архитектурные принципы:

- Глобальный namespace `window.App`
- Событийная модель (`lexitron:*`)
- Модульная структура
- Разделение логики и представления
- Versioned LocalStorage

---

## Основные слои

- `app.shell.*` — UI-каркас и навигация.
- `app.core.js` — состояние, версии, сохранение.
- `dicts/` — данные дек и тренеров.
- `app.decks.*` — работа с деками и виртуальными словарями.
- `app.trainer.js` — движок word-trainer.
- `articles.*` — подсистема артиклей.
- `prepositions.*` — подсистема предлогов.
- `ui.*` — статистика, прогресс, lifecycle и др.
- `view.*` — экраны приложения.
- `sw.js` — офлайн-режим.
